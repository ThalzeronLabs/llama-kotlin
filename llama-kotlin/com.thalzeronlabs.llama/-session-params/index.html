SessionParams

data class SessionParams(val contextSize: Int = 2048, val batchSize: Int = 512, val threads: Int = 0, val temperature: Float = 0.7f, val topK: Int = 40, val topP: Float = 0.95f, val minP: Float = 0.05f, val seed: Int = 42)(source)

Context size, threading and sampling for one LlamaSession.

The sampler is rebuilt from these values at the start of every generation, so with the same seed, the same session content and the same prompt, the model gives the same answer every time (on the same device and build).
