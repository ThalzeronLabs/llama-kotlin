LlamaSession

class LlamaSession : Closeable(source)

A conversation with a loaded model: its own context window (KV cache) and sampler.

All native work runs on one dedicated thread, so a session is safe to call from any coroutine. Only one generation runs at a time; a second call waits for the first to finish. Cancel the collecting coroutine to stop a generation mid-way.

suspend fun saveState(file: File)

Saves the session content (the KV cache and its tokens) to file, so the conversation can be resumed later, even after the app restarts, without processing the prompt again. Restore it with loadState on a session of the same model. The file holds the whole context: expect tens of megabytes for a long conversation.
