chat

fun chat(messages: List<ChatMessage>, maxTokens: Int = 512, grammar: Grammar? = null, stop: List<String> = emptyList(), temperature: Float? = null): Flow<String>(source)

Answers the last message of messages using the model's own chat template.

Pass the whole conversation on every call: keep your message list, append the user's turn, call chat, append the answer. The session keeps its KV cache between calls and only processes the part of the conversation it has not seen yet (see GenerationStats.cachedPromptTokens), so later turns start fast. A conversation that diverges from what the session holds is handled too: the cache is cut where they differ.

Parameters

grammar

restricts the output to a grammar, for example Grammar.jsonSchema; null means free text.

stop

ends the generation as soon as the output contains one of these strings (not emitted).

temperature

overrides SessionParams.temperature for this answer only (0 = greedy); null keeps the session's value. Use it for a "creativity" setting instead of opening a new session: the cache is kept.
