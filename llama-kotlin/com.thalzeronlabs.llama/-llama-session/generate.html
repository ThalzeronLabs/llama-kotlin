generate

fun generate(prompt: String, maxTokens: Int = 512, addSpecial: Boolean = true, grammar: Grammar? = null, stop: List<String> = emptyList(), temperature: Float? = null): Flow<String>(source)

Streams the model's continuation of prompt, token by token.

The prompt is appended to what the session already holds, so consecutive calls keep the history.

Parameters

maxTokens

upper bound on generated tokens.

addSpecial

add the model's begin-of-sequence token (true for the first prompt of a session).

grammar

restricts the output to a grammar, for example Grammar.jsonSchema; null means free text.

stop

ends the generation as soon as the output contains one of these strings. The stop sequence itself is not emitted.

temperature

overrides SessionParams.temperature for this call only (0 = greedy); null keeps the session's value. The KV cache is kept, so changing it costs nothing.
